FuelBand Revival

Bring an original Nike+ FuelBand back to life. Everything happens on this computer — nothing is sent anywhere.

Before you start: plug the band into this computer with its USB cable. Leave the black window that launched this page open.

1. Check the band

Confirms the band is connected and tells you whether it's already activated. This only reads — it changes nothing.

2. Activate it

Only needed if step 1 says the band is not activated. This writes settings to the band. It takes about a minute, and the band will restart partway through — that's expected.

1
Run step one, then wait until it says finished. The band restarts during this step.
2
Run step two, then press “Check band” again above.

If the band isn't found, unplug it, plug it back in, and try again.

3. Your details

The band uses your height, weight, age and sex to work out how much fuel you've earned. Fill in what you know and press Save — leave anything blank to keep what's already on the band.

Every value is read back off the band after it's written, so the output below shows what actually stuck.

4. Get your activity out

Reads the band's current fuel, step and calorie counters and saves them as a spreadsheet (CSV) and a data file (JSON) you can keep or import.

Download spreadsheet Download data file

Apple Health: Health can't be written to from a computer, so the last hop is on your iPhone — copy the CSV across and use a Shortcut with the “Log Health Sample” action. Step-by-step instructions are in tools/HEALTH.md. Note this exports the band's current totals, not a day-by-day history — the band's workout history has never been decoded.

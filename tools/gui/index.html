FuelBand Revival

Bring an original Nike+ FuelBand back to life. Everything happens on this computer — nothing is sent anywhere.

Before you start: plug the band into this computer with its USB cable. Leave the black window that launched this page open.

1. Check the band

Confirms the band is connected and tells you whether it's already activated. This only reads — it changes nothing.

2. Activate it

Only needed if step 1 says the band is not activated. This writes settings to the band. It takes about a minute, and the band will restart partway through — that's expected.

1
Run step one, then wait until it says finished. The band restarts during this step.
2
Run step two, then press “Check band” again above.

If the band isn't found, unplug it, plug it back in, and try again.
